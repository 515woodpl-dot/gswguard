# YorGuard dashboard

The Next.js dashboard provides Supabase sign-in, authenticated fleet metrics, device inventory, enrollment-token creation/copying, refresh, and platform filtering. Activity and policy views remain intentionally disabled until their API workflows are connected.

From this directory, after installing dependencies:

```text
npm install
npm run dev
```

Validation commands are `npm run lint`, `npm run typecheck`, and `npm run build`.
